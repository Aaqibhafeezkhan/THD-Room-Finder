# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, critique code and ideas
rather than people, and keep other students' personal information private.
Harassment, discrimination and publishing someone's private data are not
tolerated in issues, discussions, pull requests or the app itself.

Report problems to the maintainer privately, using the contact on
[their GitHub profile](https://github.com/arudaev). Reports
are handled confidentially. The maintainer may edit or remove content and
block participants who break these rules.
