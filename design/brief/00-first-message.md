# First message for a Phase 1 design project

Create a Claude Design project named **THD Room Finder — Focus (Phase 1)**,
attach the design system **THD Room Finder Design System**, and paste:

---

We are designing **Phase 1 of THD Room Finder: focus sessions**. The design
system is attached; read `readme.md` and the whole `brief/` folder before
anything else, especially `brief/02-focus-layer.md` and `brief/03-sessions.md`.

Today the app finds free teaching rooms at THD and shows how long they stay
free (Campus map · Rooms list · Saved). Phase 1 turns it into a daily focus
tool: a student opens a free room, presses **Start focus** (primary blue), and
the session runs **Private** by default. Others see the room as *claimed* in
dark purple, without learning who. One tap switches it to **Public**: their
batch (e.g. AIN 7) sees a violet invitation on the map and in the list. The
third tab becomes **Profile**: study profile, focus graph, saved rooms,
appearance.

Work one session at a time, in the order of `brief/03-sessions.md`. Start with
**D1 — Room detail and the focus surface**. For every screen deliver phone
(compact) and desktop (expanded) layouts, light and dark, English and German
copy, using only the system's tokens and components (new focus tokens are in
`tokens/colors.css`). Respect the rules in `brief/02-focus-layer.md`:
the schedule always wins, colour never stands alone, Private is the default.

When D1 is done, write the handback described in `brief/04-handback.md`.
