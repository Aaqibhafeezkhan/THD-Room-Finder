Small status pill. Tone communicates room state: `free` (green) for "Until 14:00", `allday` (blue) for "All day", `occupied` (red) for "Occupied now", `neutral` (grey) for generic tags.

```jsx
<Badge tone="free">Until 14:00</Badge>
<Badge tone="allday">All day</Badge>
<Badge tone="occupied">Occupied now</Badge>
```

8px radius, 12px medium text. No borders or shadows.
