The one-line top of Profile (D2): avatar initial, name, the violet batch chip
and the gear. Signed out: "Not signed in" with Set Up Study Profile; the gear
stays.

```jsx
<ProfileHeader signedIn name="Lena" batch="AIN 7" batchLabel="Batch AIN 7"
  notSignedIn="Not signed in" setupLabel="Set Up Study Profile" settingsLabel="Settings" />
```

Profile holds only what a student checks almost daily: this header, the focus
graph and saved rooms. Everything else is behind the gear.
