Gatherings

A study table for a whole group. A verified group sets a gathering in a room THD approved, and the page reads like a table's: one card, one picture, one violet action. The picture is the room set up for its type, with the room code where the front is. People appear in the order they replied, from the front or table by table: violet going, light violet maybe. Free places stay faint, so five early replies look like a lively front row, not an empty hall. Counts are a quiet line, never the headline. Spec: docs/product/organizations.md.
