# Website — Marketing Landing UI Kit

A 1:1 recreation of the THD Room Finder marketing site (`website/index.html`
in the source repo), rebuilt on the design system.

## Files
- `index.html` — the full landing page.
- `landing.jsx` — `Nav`, `Hero`, `Features`, `Footer`, composed as `Landing`.

## Sections
- **Top app bar** — logo lockup, sponsor heart, GitHub link.
- **Hero** — 80px app icon, headline, subhead, three stats (289 classrooms /
  5 min refresh / 0 accounts), and three CTAs (Use in Browser, Download APK,
  View Source).
- **Features** — a responsive `Card` grid: Real-time Availability, Building
  Filters, Schedule Lookup, Offline Support, plus the pink "Help Launch iOS"
  sponsor card.
- **Footer** — credit line + GitHub / Releases / THD links.

## Components used
`Button` · `Card` · `Logo` · `IconButton`, all from `_ds_bundle.js`.
